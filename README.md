# 韩屏译 · HanScreen v1.1

面向一加 ACE 5 的**韩文 App 实时翻译器**。不 root、不装 Xposed，靠系统屏幕捕获 + 本地韩文 OCR + 悬浮球，把任意韩文 App 的界面就地翻成中文。

---

## 下载安装包

- **直接下载 APK**：[dist/HanScreen-v1.1-arm64.apk](dist/HanScreen-v1.1-arm64.apk)（34 MB，arm64，一加 ACE 5 适用）
- 或在本仓库页面点 `dist` 目录 → `HanScreen-v1.1-arm64.apk` → Download raw
- 源码完整，可用 Android Studio 直接构建（需自行填写 `local.properties` 的 `sdk.dir`）

---

## 一、它解决什么问题

韩文 App（购物、社交、游戏、工具）几乎没有中文版。传统做法是「截图 → 切到翻译 App → 粘贴 → 看完切回来」，一次至少 20 秒。

韩屏译把这条链路压缩成**一次点击**：

1. 悬浮球常驻在屏幕边缘
2. 点一下 → 抓当前屏 → 本地识别韩文 → 翻译 → 译文直接盖在原文位置上
3. 长按 → 进入连续翻译，页面内容变化才重译（省电、不闪）

原文位置不动，所以你不用在「中文」和「按钮在哪」之间来回对照。

## 三、首次配置（3 步，约 3 分钟）

### 第 1 步：授权

打开 App → 点「启动悬浮球」：

1. 弹「显示在其他应用上层」→ 允许（悬浮球必需）
2. 弹「共享屏幕」→ 选 **共享整个屏幕** → 开始共享（抓别的 App 必需）
3. 通知权限 → 允许（保持后台运行）

> 说明：屏幕共享授权是 Android 的硬性要求，**每次手机重启后需要重新授权一次**，这是系统限制，不是 App 的问题。

### 第 2 步：配翻译引擎（关键）

App 自带韩文识别，但**翻译需要接一个翻译接口**。推荐百度翻译（国内直连、有免费额度）：

1. 浏览器打开 <https://fanyi-api.baidu.com/>
2. 注册 → 控制台 → 开发者信息 → 申请「通用文本翻译」
3. 拿到 **APP ID** 和 **密钥**
4. 回到韩屏译 → 「翻译引擎」→ 填入两个值 → 点「测试翻译」
5. 看到「→ 你好」就说明通了

免费额度按官网为准（个人认证后每月有免费字符数），日常看 App 完全够用。

**其他引擎：**

| 引擎 | 是否需要密钥 | 适用场景 |
|---|---|---|
| 百度翻译（默认） | 需要 | 国内网络，推荐 |
| 有道智云 | 需要 | 已有有道账号 |
| Google 翻译 | 不需要 | 能访问 Google 的网络 |
| 离线 ML Kit | 不需要 | 手机带 GMS 且能下载模型（国行一加通常不行） |

### 第 3 步：一加 ACE 5 专属设置（不做会被后台杀）

ColorOS 对后台管得很严，务必做这三项：

1. **电池**：设置 → 电池 → 应用耗电管理 → 韩屏译 → 选「允许后台活动」/「不限制」
2. **自启动**：设置 → 应用 → 自启动 → 允许韩屏译
3. **最近任务锁定**：多任务界面下拉韩屏译卡片加锁

App 首页的「省电设置」那行可以直接跳到系统白名单页面。

## 四、怎么用

| 操作 | 效果 |
|---|---|
| **点一下悬浮球** | 翻译当前屏幕，译文盖在原文上 |
| **长按悬浮球** | 开/关连续翻译（球上出现绿点表示已开） |
| **拖动悬浮球** | 移到不挡内容的位置，位置会记住 |
| **点屏幕空白处** | 关闭译文层 |

**两种显示模式**（设置里切）：

- **原位覆盖**：译文贴在原文位置，适合按钮、表单、短句——视线不用移动
- **底部卡片**：整屏译文按顺序列在底部，可滚动，适合长文、聊天记录、条款

**连续翻译的节奏**：默认 1 秒刷新一次，画面没变化就不重新请求（省流量、省电）。看长文建议调到 2–3 秒；刷卡列表可以调快。

### 术语表：让固定词每次译成一个样

机器翻译不稳定，同一个「장바구니」这次译「购物车」下次可能译「篮子」。术语表用来把这些词钉死。

**两种词条，各有用处：**

| 词条类型 | 例子 | 行为 |
|---|---|---|
| 单词 / 短语 | 장바구니 → 购物车 | 句子里出现就强制替换，保证一致 |
| 完整句子 | 장바구니에 담았습니다 → 已加入购物车 | 整段完全匹配时直接返回，不发请求、零延迟、不耗额度 |

**怎么加：**

1. 首页 → 术语表 → 「管理术语表」
2. 点「＋ 添加术语」，左填韩文、右填中文，改完自动保存
3. 词多时用「批量导入」，一行一条，`=` 或 `→` 分隔：

```
장바구니 = 购物车
배송조회 → 物流跟踪
```

**内置 45 条**电商/界面高频词（购物车、结算、物流、登录、优惠券、确认、取消…），装完即用；改乱了点「恢复默认术语表」一键还原 45 条。

**容错**：词条内部允许任意空格，所以「배송조회」和「배송 조회」算同一条，不会被界面上的排版差异漏掉。

**取舍要清楚**：单词级替换是「先换成占位符再送翻译」，能保证术语正确，但长句可能读起来略生硬（`장바구니에 담았습니다` → 「包含在购物车中」，而机器直译原本是「已添加到购物车」）。如果某句你希望完全按自己的说法，就把整句加成词条，走精确匹配那条路。

## 五、技术实现

```
┌─────────────┐   MediaProjection    ┌──────────────┐
│  系统屏幕     │ ───────────────────► │ ImageReader  │ 缓存最新一帧
└─────────────┘   VirtualDisplay      └──────┬───────┘
                                             │ Bitmap
                                      ┌──────▼───────┐
                                      │ ML Kit 韩文OCR │ 离线，不联网
                                      └──────┬───────┘
                                             │ 行文本框
                                      ┌──────▼───────┐
                                      │ 行聚类成段     │ 避免一句拆成多次请求
                                      └──────┬───────┘
                                             │ 段落文本
                                      ┌──────▼───────┐
                                      │ 术语表         │ 整句精确匹配 / 词条占位符保护
                                      └──────┬───────┘
                                             │
                                      ┌──────▼───────┐
                                      │ 翻译引擎       │ 批量 + LRU/磁盘缓存
                                      └──────┬───────┘
                                             │ 译文 + 原坐标
                                      ┌──────▼───────┐
                                      │ 悬浮窗覆盖层   │ 原位绘制 / 底部卡片
                                      └──────────────┘
```

关键设计：

- **不走无障碍服务**：只读无障碍节点拿不到图片、WebView、游戏画面里的文字，覆盖面太窄
- **OCR 离线**：截图不出手机，只有识别出的文字发给翻译接口
- **静态页面也能抓**：屏幕不变时系统不产新帧，所以常驻监听并缓存最后一帧
- **避免抓到自己**：抓帧前把译文层隐藏 45ms，防止把中文再 OCR 一遍
- **缓存两级**：内存 LRU + 磁盘，同屏重复文本不重复请求；译文与原文相同则不写缓存（防污染）
- **术语表版本进缓存键**：改任何一条术语都会让旧缓存自动失效，新译法立刻生效，不会命中旧结果

## 六、已验证 / 已知限制

**已在 Android 15 模拟器（1080×2400，API 37）用交付的 `HanScreen-v1.0-arm64.apk` 实测通过：**

| 环节 | 结果 |
|---|---|
| 安装、启动 | 正常，无崩溃 |
| 悬浮窗授权 → 悬浮球 | 显示在系统图库之上，可点可拖 |
| 屏幕捕获授权 | 强制「Share entire screen」，不出现「单个应用」选择器 |
| 全屏抓帧 | 1080×2400 |
| ML Kit 韩文 OCR | 19 行识别出 12 行韩文 |
| 行→段聚类 | 12 段 |
| 翻译 | 12 段全部译出（Google 引擎，2.5–4.6 s） |
| 覆盖层 | 逐行原位覆盖，卡片完整盖住原文，中文清晰 |
| 实际译文样例 | 한국어 앱 번역 테스트→韩语应用翻译测试；안녕하세요→你好；오늘 날씨가 정말 좋네요→今天天气真好；주문이 완료되었습니다→您的订单已完成。；배송 조회→交货追踪；장바구니에 담았습니다→已添加到购物车 |
| 术语表 · 整句精确匹配 | 구매하기→立即购买、장바구니→购物车，不发请求 |
| 术语表 · 词条替换 | 배송 조회→**物流跟踪**（未加词条时机器译为「交货追踪」），并容忍词内空格 |
| 术语表 · 增删改持久化 | 新增行→输入→退出重进仍在；「恢复默认」回到 45 条 |
| 缓存 | 同一屏二次点击 5.3 s → 1.8 s；改术语后按 revision 自动失效重译 |

验证截图见 `docs/verify-*.png`；测试用韩文样张见 `samples/kotest.png`。

**开发过程中实测发现并修掉的 5 个真问题（都已验证修复）：**

1. `when (intent?.action)` 不做智能转型 → 服务崩溃（编译期拦截）
2. Android 14+ 默认弹「共享单个应用」→ 悬浮球抓不到别的 App，改为强制整屏
3. 静态页面不产新帧 → 点悬浮球拿不到图，改为常驻监听 + 缓存最后一帧
4. 抓帧时把自家译文层截进去 → 抓帧前隐藏 45ms
5. 底板 94% 不透明 → 原文透出形成重影，改全不透明；另外译文=原文时不写缓存，避免错误结果被固化

**已知限制：**

1. **只支持竖屏**：横屏（部分游戏）需要重建虚拟屏，当前版本未处理
2. **只翻韩文**：英文/数字保留原文，不做二次翻译
3. **安全窗口抓不到**：银行、支付类 App 开了 FLAG_SECURE，截出来是黑屏，属系统保护
4. **每次重启要重新授权屏幕共享**：Android 14+ 强制规定
5. **翻译延迟**：0.6–2 s（百度批量接口）/ 2.5–4.6 s（Google 逐条），取决于引擎与网络
6. **自家界面不参与翻译**：系统会把「正在投屏的 App 自己」从截屏里遮掉，这是防止无限镜面，不影响翻译第三方 App
7. **术语替换会让长句略生硬**：单词级替换保证术语正确，但语序可能变僵；要更自然的说法就把整句加成词条走精确匹配

## 七、源码结构

```
app/src/main/java/com/hanscreen/translator/
├── MainActivity.kt              设置页 + 权限流程
├── GlossaryActivity.kt          术语表管理（增删改 / 批量导入 / 恢复默认）
├── App.kt / Prefs.kt            全局单例与配置
├── core/
│   ├── Hangul.kt                韩文字符检测与占比过滤
│   ├── Http.kt                  HttpURLConnection 封装 + MD5/SHA256
│   └── Screen.kt                屏幕尺寸
├── capture/ScreenCapture.kt     虚拟屏 + 帧缓存
├── ocr/
│   ├── OcrEngine.kt             ML Kit 韩文识别（bundled，无需 GMS）
│   └── TextGrouper.kt           行→段落聚类
├── translate/
│   ├── TranslationEngine.kt     引擎接口 + 工厂
│   ├── Glossary.kt              术语表（精确匹配 / 占位符保护 / 版本号）
│   ├── BaiduEngine.kt           批量（多行合并成一次请求）
│   ├── YoudaoEngine.kt          有道 v3 签名
│   ├── GoogleEngine.kt          免费接口
│   ├── MlKitEngine.kt           端侧模型
│   ├── TranslationCache.kt      两级缓存
│   └── EngineCache.kt           引擎单例
├── overlay/
│   ├── FloatingBallView.kt      悬浮球（拖动/点击/长按）
│   ├── OverlayController.kt     覆盖窗口（两种模式）
│   └── OverlayPaintView.kt      原位绘制 + 字号自适应
└── service/TranslatorService.kt 前台服务，串起整条链路
```
